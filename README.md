# thakur.08 - authentic non-veg kitchen & grill

A high-performance modern web application for **thakur.08**, a premium non-veg dining and artisanal charcoal grill experience.

## features

- **authentic non-veg culinary showcase**: slow-cooked dum biryanis, signature clay tandoor kebabs, juicy steaks, butter chicken, and fiery seafood delicacies.
- **meat purity & quality pledge**: 100% farm-fresh cuts, secret ancient spice rubs, and artisanal charcoal pit grilling.
- **interactive dish plate / cart**: dynamic dish drawer with real-time bill breakdown, spice level customization, and instant reservation or takeaway order checkout.
- **table reservation system**: seamless table booking with guest size, timing slot selection, and meat preference notes.
- **ambient charcoal & ember UI theme**: dark high-contrast design featuring crimson red, flame amber accents, glassmorphism, and micro-interactions.
- **ci/cd workflow**: automated vitest test runner and production vite build pipeline.

## tech stack

- **react 19**
- **vite 8**
- **lucide-react** for icons
- **vitest & testing library** for test suite
- **oxlint** for fast code linting

## getting started

```bash
# install dependencies
npm install

# run development server
npm run dev

# run test suite
npm test

# build for production
npm run build
```
